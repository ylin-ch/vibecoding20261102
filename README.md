# A small corner of the internet

A responsive, interactive test page for GitHub Pages. Plain HTML, CSS, and JavaScript; no build step or dependencies.

## Publish

1. Push this repository to the `main` branch on GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Visit `https://ylin-ch.github.io/vibecoding20261102/` after deployment finishes.

The signal counter is stored only in each visitor's browser.

## Preview locally

Run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000/`.
